# file and directory naming rules

rules for repository files and directories:

1. strictly small case:
   - all file names, directory names, comments, and strings must be written in small case (lowercase).

2. use `-` (hyphen) for word separation:
   - use kebab-case (`-`) for multi-word folders and files: e.g. `input-from-user.py`, `comparison-operators.py`, `conditional-statements`.
   - never use underscores `_` or spaces in file or directory names.

3. directory naming:
   - use kebab-case with `-`: e.g. `variables-and-data-types`, `conditional-statements`.
   - use plural form for question/problem sets: `practice-questions`.

4. file naming:
   - python scripts use kebab-case: e.g. `data-types.py`, `input-from-user.py`.
   - practice problem files use `q<number>.py` (e.g. `q1.py`, `q2.py`).
   - documentation files must be lowercase `.md` (e.g. `readme.md`, `dsa-roadmap.md`).

5. code cleanliness:
   - all python files must be syntactically valid. invalid syntax examples must be commented out.
