# commit message rules

rules for all git commits:

1. format:
   `<scope>: <short imperative description in small case>`

   examples:
   - `init: add roadmaps, curriculum, and rules`
   - `python: variables and data types`
   - `python: nested if-else statement`
   - `python: solve operators practice questions`

2. small case & hyphen rules:
   - strictly small case only (no uppercase letters).
   - use standard hyphen `-` for compound terms (e.g. `if-else`, `nested-if-else`).
   - use imperative mood ("add", "solve", "update").
   - keep length between 40 and 72 characters.
   - no trailing period at the end of the subject.

3. trailers & signing:
   - include sign-off: `Signed-off-by: itsurajx <surajxcode@gmail.com>`
   - every commit must be gpg-signed with your verified key.
